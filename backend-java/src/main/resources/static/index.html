ABOUT THE PROJECT

AI-assisted insight, made easier to understand.

KneeSense is an academic project exploring the use of deep learning to estimate knee osteoarthritis severity from a single knee X-ray. The planned experience combines a KL grade estimate, a Grad-CAM visual explanation and readable summaries.

0–4Kellgren–Lawrence grading scale used to represent the estimated osteoarthritis grade.
HOW IT WORKS

From X-ray to assessment summary

The portal is connected to the backend. During development, results may be simulated until the real ML service is enabled.

01

Submit a knee X-ray

The patient selects a knee X-ray image. The application validates the file before sending it to the AI service.

02

AI-assisted assessment

The planned EfficientNet-B0 model estimates a KL grade. Grad-CAM provides a visual explanation of image regions that influenced the prediction.

03

Review the result

The application presents the grade, confidence, visual explanation and a patient-friendly summary. Doctors have a separate clinician-oriented view.

WHAT KNEESENSE INCLUDES

Three parts of the assessment experience

KL grade estimation

A model-generated estimate on the Kellgren–Lawrence scale from Grade 0 to Grade 4.

Visual explanation

A Grad-CAM heatmap intended to illustrate which image regions influenced the model output.

Readable reports

Separate patient-friendly and clinician-oriented summaries, shown according to account permissions.

Important: KneeSense is an academic prototype, not a medical device or a substitute for professional diagnosis. AI-generated outputs may be incorrect and must be reviewed by a qualified healthcare professional. Do not use this prototype to make medical decisions.
